# Kestrel Budget (synthetic)

SYNTHETIC DATA: fictional app, fictional reviews, generated by releasepulse.synthetic for evaluation.

Kestrel Budget is a fictional personal budgeting app that connects to bank accounts. Held-out set: not used for tuning.

- `feedback.csv`: 345 items (app-store reviews and issue tickets)
- `releases.csv`: 5 releases with release notes
- `gold.json`: planted mentions with character spans, regressions, improvements, traps

Regenerate with `uv run releasepulse synth kestrel`.
