# Tallynote (synthetic)

SYNTHETIC DATA: fictional app, fictional reviews, generated by releasepulse.synthetic for evaluation.

Tallynote is a fictional notes and to-do app for phones, tablets and laptops. Development set: prompts and thresholds were tuned on it.

- `feedback.csv`: 365 items (app-store reviews and issue tickets)
- `releases.csv`: 5 releases with release notes
- `gold.json`: planted mentions with character spans, regressions, improvements, traps

Regenerate with `uv run releasepulse synth tallynote`.
